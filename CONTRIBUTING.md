# Contributing to node-cli-banner

Thanks for helping improve **node-cli-banner**.

## Development

```bash
git clone https://github.com/theinfyark/node-cli-banner.git
cd node-cli-banner
npm install
npm test
npm run build
```

## Guidelines

- Keep the public API small, predictable, and well typed
- Prefer zero/minimal dependencies
- Add tests for bug fixes and new features
- Update `CHANGELOG.md` for user-facing changes
- Use clear commit messages (do not add Cursor co-author trailers)
